# Terminal palette sources

Cerebro Default preserves the original Cerebro overrides. Xterm Default uses an empty ITheme, allowing xterm.js to supply every default.

Named palettes are bundled from the maintained [iTerm2-Color-Schemes Windows Terminal collection](https://github.com/mbadolato/iTerm2-Color-Schemes/tree/master/windowsterminal). Keys are translated (purple → magenta, cursorColor → cursor); cursorAccent uses the background. Kanagawa Wave, Dragon, and Lotus also use the background as selectionForeground so text remains readable against their inverted selection backgrounds.

- Nord: `Nord.json`
- Catppuccin Mocha: `Catppuccin Mocha.json`
- Catppuccin Latte: `Catppuccin Latte.json`
