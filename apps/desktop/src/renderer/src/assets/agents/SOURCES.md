# Agent logo sources

Assets come from [theSVG](https://thesvg.org), pinned to revision `329b78bb65c5540ef522ed4620cb84c16a3951b8`:

- Claude Code: [catalog](https://thesvg.org/icon/claude-code), [color.svg](https://github.com/glincker/thesvg/blob/329b78bb65c5540ef522ed4620cb84c16a3951b8/public/icons/claude-code/color.svg).
- Codex: [catalog](https://thesvg.org/icon/codex), [default.svg](https://github.com/glincker/thesvg/blob/329b78bb65c5540ef522ed4620cb84c16a3951b8/public/icons/codex/default.svg).
- Pi: [catalog](https://thesvg.org/icon/pi), [default.svg](https://github.com/glincker/thesvg/blob/329b78bb65c5540ef522ed4620cb84c16a3951b8/public/icons/pi/default.svg). Its viewBox is cropped to the mark bounds to match the other icons' optical size.

These local assets are rendered as CSS masks. Claude Code keeps its source terracotta color; Codex and Pi inherit the button foreground. Names belong to the buttons' accessible labels; the marks are decorative. Brand ownership remains with the respective owners. See theSVG's [trademark policy](https://github.com/glincker/thesvg/blob/329b78bb65c5540ef522ed4620cb84c16a3951b8/TRADEMARK.md).
